# Contributing to FRI <-> NFI Converter

This project is maintained by the Ontario Ministry of Natural Resources (MNR). External contributions and suggestions are welcome following the guidelines below.

## How to Contribute

1. **Fork & Branch**: Fork the repository and create a descriptive feature branch (e.g. `feature/support-variety-code`).
2. **Coding Standards**:
   - Follow [PEP 8](https://peps.python.org/pep-0008/) style guidelines.
   - Maintain full test coverage and ensure all existing CLI tests pass.
   - Preserve standard script copyright headers at the top of all new Python source files.
3. **Pull Requests**: Submit a pull request with a clear description of the problem solved or feature added.
